MoEMoKA 向量化 Forward
Expert Loop → einsum + 跨专家 Cross-Attn

MoE-MoKA 在 MoE-LoRA 基础上引入了模态特定 A 矩阵和跨模态 Cross-Attention。原始实现对 N=8 个专家逐一串行计算， 造成 8× Python dispatch + 8× 小矩阵乘法开销。向量化后，专家维度通过 einsum 融合，Cross-Attention 同时处理所有专家。

01

架构总览 — MoEMoKA 与 MoELoRA 的区别

MoELoRA 每个专家只有一个 A 矩阵（对所有 token 共用）；MoEMoKA 每个专家有 两个 A 矩阵，分别处理文本 token 和视觉 token：

组件MoELoRAMoEMoKA
A 矩阵 单个 W_A_i，处理全部 token A_text_i 处理文本 token，A_vis_i 处理视觉 token
B 矩阵 每专家独立 B_i 每专家独立 B_i（相同）
Cross-Attention 无 视觉 token 以文本 token 为 K/V，在 rank-r 空间做注意力
Forward 公式 ΔW·x = B·Σᵢ wᵢ·(Aᵢ·x)·s ΔW·x = Σᵢ wᵢ·Bᵢ·[Aᵢᵗ·xᵗ ; Aᵢᵛ·xᵛ + Att(Aᵢᵛ·xᵛ, Aᵢᵗ·xᵗ)]·s
过文本化修复 否（梯度仍共享 A） 是（A_text/A_vis 独立，梯度不互相污染）

Token mask 编码：2 = 文本，1 = 视觉，0 = padding（始终排除）。

03

原始 Loop 实现 — 问题在哪里

mokamoelora.py · 旧版（已替换）# 对 N=8 个专家逐一串行执行
for i, expert in enumerate(self.lora_experts[adapter]):
    r_per = expert.lora_A_text.out_features

    # 分别调用两个 A 矩阵 → 2 次小 CUDA kernel
    out_text = expert.lora_A_text(flat_text)   # (n_text, r_per)
    out_vis  = expert.lora_A_vis(flat_vis)     # (n_vis,  r_per)

    a_comb = torch.zeros(B, S, r_per, ...)
    if has_text: a_comb[text_mask] = out_text
    if has_vis:
        if has_text:
            out_vis = self._cross_attention(out_vis, out_text, ...)
        a_comb[vis_mask] = out_vis

    out_i = expert.lora_B(a_comb)             # (B, S, d_out)
    expert_sum += router_weights[:,:,i].unsqueeze(-1) * out_i  # 累加

开销分析：

  • 每次循环：2 次 A-forward（各自 1 次 CUDA kernel）+ 1 次 B-forward = 3× kernel launch × 8 专家 = 24 次小 kernel
  • Cross-Attention：每个专家独立调用 _cross_attention()，内部还有 batch 维度的 Python for loop
  • 每次 kernel launch 有 ~10-20μs 固定开销，24 次 = 约 240-480μs 纯 overhead
  • 8 个 a_comb 临时张量的 alloc/free 各自独立，显存碎片化
04

向量化实现 — _lora_vectorized()

mokamoelora.py · _lora_vectorized()# 1. 一次性 stack 所有专家的权重
A_text = torch.stack([e.lora_A_text.weight for e in experts], dim=0)  # (N, r_per, d_in)
A_vis  = torch.stack([e.lora_A_vis.weight  for e in experts], dim=0)  # (N, r_per, d_in)
B_all  = torch.stack([e.lora_B.weight       for e in experts], dim=0)  # (N, d_out, r_per)

# 2. 所有专家同时计算 A·x（1 次 einsum 替代 N 次 matmul）
out_text_N = torch.einsum('td,nrd->tnr', flat_text, A_text)  # (n_text, N, r_per)
out_vis_N  = torch.einsum('vd,nrd->vnr', flat_vis,  A_vis)   # (n_vis,  N, r_per)

# 3. Cross-Attention：batch loop 保留，但 N 专家同时处理
if has_vis and has_text:
    out_vis_N = self._cross_attention_vec(out_vis_N, out_text_N, ...)

# 4. Scatter 到 (B, S, N, r_per) 再一次性过 B
a_comb = torch.zeros(B, S, N, r_per, ...)
if has_text: a_comb[text_mask] = out_text_N
if has_vis:  a_comb[vis_mask]  = out_vis_N
out_all = torch.einsum('bsnr,nor->bsno', a_comb, B_all)  # (B, S, N, d_out)

# 5. Router 加权求和
return (router_weights.unsqueeze(-1) * out_all).sum(dim=2)  # (B, S, d_out)

kernel 次数从 24 次 降到 3-4 次（stack、2 × einsum、B einsum）。

05

Cross-Attention 优化 — _cross_attention_vec()

Cross-Attention 存在 batch 维度的 Python for loop（每个样本的视觉/文本 token 数量不同，无法直接 pad-free 向量化）。 原始版本在循环内对每个专家独立计算；向量化版本在循环内 同时处理所有 N 专家：

旧版：每专家独立注意力
for b in range(batch_size):
    q  = query[v0:v0+nv]  # (nv, r_per)
    kv = key_val[t0:t0+nt] # (nt, r_per)
    # 单专家 attention
    score = q @ kv.T / sqrt(r)  # (nv, nt)
    attn  = softmax(score)
    out   = q + attn @ kv  # (nv, r_per)

# 调用 N 次（8× for loop 外层）
新版：N 专家同时计算
for b in range(batch_size):
    q  = query  [v0:v0+nv]  # (nv, N, r_per)
    kv = key_val[t0:t0+nt]  # (nt, N, r_per)
    # 所有专家一次 einsum
    sc = einsum('vnr,tnr->vtn', q, kv) # (nv,nt,N)
    at = softmax(sc, dim=1)
    up = einsum('vtn,tnr->vnr', at, kv) # (nv,N,r)

# batch loop 不可消除（可变长度）
为什么 batch loop 无法消除
每个样本的文本 token 数（n_text）和视觉 token 数（n_vis）不同，flat_text/flat_vis 是将 batch 中所有样本 concat 后的结果。 若要向量化 batch 维度，需要 padding + attention mask，实现更复杂，且 B=1（训练时每卡 batch=4~8）时收益有限。 当前方案（batch loop + N 专家 einsum）已消除主要瓶颈。
06

einsum 符号详解

索引含义

bBbatch size（训练时 = per_device_train_batch_size） sS序列长度（text + visual + pad，完整长度） tn_textgather 后的文本 token 总数（flat，已去 pad） vn_visgather 后的视觉 token 总数（flat，已去 pad） nN=8专家数量 rr_per每专家的 rank（= total_r / N = 32/8 = 4） dd_in输入维度（LLaMA-7B: 4096） od_out输出维度（通常 = d_in）

逐步推导

Step 1 · 文本 token 过 A_text（所有专家）# flat_text:  (n_text, d_in)   — 所有文本 token，已 gather
# A_text:     (N, r_per, d_in) — N 个专家的 A_text 矩阵

out_text_N = torch.einsum('td,nrd->tnr', flat_text, A_text)
#   t: n_text token 位置
#   d: 输入维度（求和/缩并）
#   n: 专家维度（保留）
#   r: rank 维度（保留）
#   输出 (n_text, N, r_per)：每个 token 在每个专家中的低秩表示
Step 2 · 视觉 token 过 A_vis（所有专家）out_vis_N = torch.einsum('vd,nrd->vnr', flat_vis, A_vis)
#   v: n_vis token 位置
#   输出 (n_vis, N, r_per)
Step 3 · Cross-Attention（per batch sample，all N experts）# scores: 视觉 token 对文本 token 的注意力分数（所有专家）
scores = torch.einsum('vnr,tnr->vtn', q, kv)
#   v: n_vis，t: n_text → (n_vis, n_text, N) 每专家独立的注意力矩阵
# update: attn 加权后的文本信息注入视觉 token
update = torch.einsum('vtn,tnr->vnr', attn, kv)
#   vt→v: 对 n_text 维加权聚合（softmax 后已归一化）
Step 4 · 所有专家过 B（一次 einsum）# a_comb: (B, S, N, r_per) — 已 scatter 回全序列
# B_all:  (N, d_out, r_per)
out_all = torch.einsum('bsnr,nor->bsno', a_comb, B_all)
#   r: rank 维（求和/缩并）
#   输出 (B, S, N, d_out)：每个位置、每个专家的输出

# Router 加权求和 → (B, S, d_out)
result  = (router_weights.unsqueeze(-1) * out_all).sum(dim=2)
