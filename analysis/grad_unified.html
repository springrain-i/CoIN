① 研究目标

研究问题：持续指令微调（T1→T8）中，MoELoRA 的文本梯度是否系统性主导参数更新，且这种主导是否随任务序号单调加剧？

核心指标：梯度主导比值，三个视角同时记录（全部精确）

$$R_A(k) = \frac{\|G^t_A\|_F}{\|G^v_A\|_F}, \qquad R_B(k) = \frac{\|G^t_B\|_F}{\|G^v_B\|_F}, \qquad R_{\Delta W}(k) = \frac{\|G^t_{\Delta W}\|_F}{\|G^v_{\Delta W}\|_F}$$
$$R_{X,\text{tok}}(k) = \frac{\|G^t_X\|_F \,/\, n_{\text{text}}}{\|G^v_X\|_F \,/\, n_{\text{vis}}}, \qquad X \in \{A,\; B,\; \Delta W\}$$

其中（全部精确外积求和，全 batch）：

  $G^t_A\,[n,r,d] = \displaystyle\sum_{b,\,t\in\text{text}} \frac{\partial L}{\partial \text{out}_A}[b,t,n,r] \cdot \text{lora_x}[b,t,d]$  —  形状 $(N,\,r,\,d_{\text{in}})$
  $G^t_B\,[n,d,r] = \displaystyle\sum_{b,\,t\in\text{text}} \frac{\partial L}{\partial \text{out}_B}[b,t,n,d] \cdot \text{out_A}[b,t,n,r]$  —  形状 $(N,\,d_{\text{out}},\,r)$
  $\|G^t_{\Delta W}\|_F^2 = \displaystyle\sum_b \bigl(K_{g,b} \odot K_{x,b}\bigr)_{\text{sum}}$， 直接构造 $G^t_{\Delta W}=\sum_{b,t\in\text{text}}\mathbf{g}_{bt}^\top\mathbf{x}_{bt}$，取 $\|\cdot\|_F$（精确，见 Step 4b）
预期现象对应指标
文本梯度始终主导$R_A,\;R_B,\;R_{\Delta W} > 1$（所有任务）
主导随任务序列加剧$R_A(k),\;R_B(k),\;R_{\Delta W}(k)$ 随 $k$ 单调递增
消除 token 数效应后偏置仍成立$R_{A,\text{tok}},\;R_{B,\text{tok}},\;R_{\Delta W,\text{tok}} > 1$
这是视觉模态知识更易被遗忘的机制性原因与 text/visual acc 差距相关

Step 3 · 从 ∂L/∂h 到 ∂L/∂W_A 的完整推导（W_A 和 W_B）

W_A 的推导

Forward 展开（$t$ = 序列位置，$i$ = 输出维度 $r$，$j$ = 输入维度 $d_{\text{in}}$）：

$$h_A[t,\,i] \;=\; \sum_j W_A[i,j]\cdot x[t,j]$$

对 $W_A[i,j]$ 链式法则：

$$\frac{\partial L}{\partial W_A[i,j]} = \sum_t \underbrace{\frac{\partial L}{\partial h_A[t,i]}}_{g_{\text{out}_A}[t,i]} \cdot \underbrace{\frac{\partial h_A[t,i]}{\partial W_A[i,j]}}_{\displaystyle= x[t,j]} = \sum_t g_{\text{out}_A}[t,\,i]\cdot x[t,\,j]$$

写成矩阵形式：

$$\frac{\partial L}{\partial W_A} = g_{\text{out}_A}^\top \cdot x \quad \underbrace{(r\times T)\cdot(T\times d_{\text{in}})}_{= r\times d_{\text{in}}\;\checkmark}$$

W_B 的推导（MoE 版，B shape = $(N,\,d_{\text{out}},\,r)$）

Forward：

$$\text{out}_B[b,t,n,d] = \sum_r B[n,d,r]\cdot\text{out}_A[b,t,n,r]$$

对 $B[n,d,r]$ 链式法则：

$$\frac{\partial L}{\partial B[n,d,r]} = \sum_{b,t} \frac{\partial L}{\partial \text{out}_B[b,t,n,d]}\cdot\text{out}_A[b,t,n,r]$$

按模态分解（精确，全 batch）：

$$G^t_B[n,d,r] = \sum_{b,\;t\in\text{text}} g_{\text{out}_B}[b,t,n,d]\cdot\text{out_A}[b,t,n,r]$$ $$G^v_B[n,d,r] = \sum_{b,\;t\in\text{vis}} g_{\text{out}_B}[b,t,n,d]\cdot\text{out_A}[b,t,n,r]$$
out_A.detach() 形状 $(B,T,N,r)=(8,700,8,4)\approx 0.36\text{MB}$ — 极小，直接存闭包。

ΔW = BA 合并梯度（精确）

$\Delta W(x)=B\cdot A\cdot x = \text{lora_out}/\text{scaling}$（MoE 下为 router 加权和）

$$\frac{\partial L}{\partial(\Delta W)[d_o,\,d]} = \sum_t \frac{\partial L}{\partial\text{lora_out}[t,\,d_o]}\cdot\text{lora_x}[t,\,d] = g_{\text{lora_out}}^\top\cdot\text{lora_x} \;\in\mathbb{R}^{d_{\text{out}}\times d_{\text{in}}}$$

直接按模态累加外积构造 $G^t_{\Delta W}$（33 MB/层，8 卡显存充裕），精确取范数。见 Step 4b。

物理含义：$\Delta W$ 直接测量"LoRA 等效权重更新方向中 text 贡献占比"，与 $W_A$（输入压缩子空间偏置）互补。

加法封闭性（三个指标均精确成立）

因为 token 空间中 $x_{\text{text}}$ 与 $x_{\text{vis}}$ 位置不重叠，矩阵乘法分配律直接给出精确拆分：

$$\frac{\partial L}{\partial W_A} = G_{\text{out}_A}^\top(x_{\text{text}}+x_{\text{vis}}) = G^t_A + G^v_A$$ $$\frac{\partial L}{\partial B} = G^t_B + G^v_B, \qquad \frac{\partial L}{\partial(\Delta W)} = G^t_{\Delta W} + G^v_{\Delta W}$$
关键性质：$G^t + G^v = $ 完整梯度，精确等式，无近似。三个指标的模态分解均严格成立。

精确指标 vs 之前的代理指标：

Step 4b · ΔW 梯度矩阵——直接构造（精确）

$G^t_{\Delta W}$ 上标 $t$ 即"文本模态贡献"的定义。完整梯度精确拆分： $$\frac{\partial L}{\partial(\Delta W)} = \underbrace{\sum_{b,\,t\in\text{text}} \mathbf{g}_{bt}^\top\mathbf{x}_{bt}}_{G^t_{\Delta W}} + \underbrace{\sum_{b,\,t\in\text{vis}} \mathbf{g}_{bt}^\top\mathbf{x}_{bt}}_{G^v_{\Delta W}} \;\in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$$

符号含义：

  • $\mathbf{g}_{bt} = \dfrac{\partial L}{\partial \text{lora\_out}[b,t]} \in \mathbb{R}^{d_{\text{out}}}$ — hook 捕获的梯度向量
  • $\mathbf{x}_{bt} = \text{lora\_x}[b,t] \in \mathbb{R}^{d_{\text{in}}}$ — 前向存入闭包的输入激活
  • $\mathbf{g}_{bt}^\top \mathbf{x}_{bt} \in \mathbb{R}^{d_{\text{out}}\times d_{\text{in}}}$ — 单 token 对 $\Delta W$ 的外积贡献，精确等于梯度分量

实现

直接累加外积，得到精确的 $G^t_{\Delta W}$：

G_t = zeros(d_out, d_in) # 形状 (4096, 4096)，bf16 ≈ 33MB for b in batch: G_t += g_lora_out[b, text_idx].T @ lora_x[b, text_idx] # (d_out, T_t) @ (T_t, d_in) → (d_out, d_in) g_tdW = G_t.norm() # 精确 ‖G^t_ΔW‖_F

内存分析

张量形状大小 (bf16)说明

$G_v$$(4096,4096)$33 MB同上

8 × 24 GB RTX 3090，ZeRO-3 参数分片后每卡显存充裕，66 MB 额外峰值完全可接受。三个指标（$R_A$、$R_B$、$R_{\Delta W}$）现在全部精确，无近似。

Step 5 · 为什么 R 远大于 1？主要驱动机制

Causal LM 只对回答 token 计算 loss，视觉 token 的梯度需经由多跳 causal attention 反传，每跳衰减约 ×0.1~0.2，到达视觉位置时幅度已大幅降低。这一结构性不对称是 R >> 1 的主要原因，与模型或任务无关。

此外，per-token 归一化（$R_{\text{tok}}$）会进一步消除文本/视觉 token 数量差异对 R 的影响，只保留纯粹的模态梯度强度比。待 T1 重跑确认具体数值。

④ 代码实现

核心：coinmoelora.py — 三个 backward hook

触发顺序由计算图决定：hook_lora_out（ΔW，最先）→ hook_B（W_B 精确，需 out_A_ref）→ hook_A（W_A，最后，负责 flush）。x_ref 在 hook_A 释放；hook_lora_out 读时仍有效。

if getattr(self, '_log_gradients', False): raw_mask = self.token_mask logger_ref = getattr(self, '_grad_logger', None) layer_name = getattr(self, '_grad_layer_name', '') step = logger_ref.step if logger_ref is not None else 0 log_every = logger_ref.log_every_n_steps if logger_ref is not None else 1 A_shape, A_dtype, A_device = A.shape, A.dtype, A.device # ZeRO-3 safe out_A = torch.einsum('bti,nri->btnr', lora_x, A) # (B,T,N,r_per) out_B = torch.einsum('btnr,nor->btno', out_A, B) # (B,T,N,d_out) x_ref = [lora_x.detach()] # freed in hook_A; hook_lora_out reads first # ── hook_lora_out: ΔW=BA，gram matrix trick ────────────────────────────── # G^t_ΔW = Σ_{b,t∈text} g_bt^T x_bt, shape (d_out, d_in) ≈ 33MB bf16 — 精确 def hook_lora_out(g_lora_out): # (B,T,d_out) if logger_ref is None or step % log_every != 0: return x_cap = x_ref[0] d_out, d_in = B_shape[1], A_shape[2] with torch.no_grad(): G_t = torch.zeros(d_out, d_in, dtype=A_dtype, device=A_device) G_v = torch.zeros(d_out, d_in, dtype=A_dtype, device=A_device) n_text, n_vis = 0, 0 for b in range(raw_mask.shape[0]): t_idx = (raw_mask[b] == 2); out_A_ref[0] = None # release ~0.36MB if logger_ref is None or step % log_every != 0: return with torch.no_grad(): G_t_B = torch.zeros(B_shape, dtype=A_dtype, device=A_device) G_v_B = torch.zeros(B_shape, dtype=A_dtype, device=A_device) for b in range(raw_mask.shape[0]): t_idx = (raw_mask[b] == 2); v_idx = (raw_mask[b] == 1) if t_idx.any(): G_t_B += torch.einsum('tnd,tnr->ndr', g_out_B[b,t_idx], out_A_cap[b,t_idx]) if v_idx.any(): G_v_B += torch.einsum('tnd,tnr->ndr', g_out_B[b,v_idx], out_A_cap[b,v_idx]) logger_ref._pending[(step, layer_name)] = { 'g_tB': G_t_B.norm().item(), 'g_vB': G_v_B.norm().item(), } # ── hook_A: W_A 精确，全 batch 累加，最后 flush ──────────────────────────── def hook_A(g_out_A): # (B,T,N,r_per) x_cap = x_ref[0]; x_ref[0] = None if logger_ref is None or step % log_every != 0: return with torch.no_grad(): G_t = torch.zeros(A_shape, dtype=A_dtype, device=A_device) G_v = torch.zeros(A_shape, dtype=A_dtype, device=A_device) for b in range(raw_mask.shape[0]): t_idx = (raw_mask[b] == 2); v_idx = (raw_mask[b] == 1) if t_idx.any(): G_t += torch.einsum('tnr,td->nrd', g_out_A[b,t_idx], x_cap[b,t_idx]) if v_idx.any(): G_v += torch.einsum('tnr,td->nrd', g_out_A[b,v_idx], x_cap[b,v_idx]) eB = logger_ref._pending.pop((step, layer_name), {}) edW = logger_ref._pending_dw.pop((step, layer_name), {}) logger_ref._flush( step, layer_name, G_t.norm().item(), G_v.norm().item(), eB.get('g_tB',0.), eB.get('g_vB',0.), edW.get('g_tdW',0.), edW.get('g_vdW',0.), edW.get('n_text',0), edW.get('n_vis',0), ) lora_out = (out_B * router.unsqueeze(-1)).sum(dim=2) * self.scaling[active] if lora_out.requires_grad: lora_out.register_hook(hook_lora_out) if out_B.requires_grad: out_B.register_hook(hook_B) if out_A.requires_grad: out_A.register_hook(hook_A) return lora_out

ModalGradientLogger — 记录器主类

负责 attach 到模型、协调 hook 结果、写 CSV。每个 rank 写独立文件，不会 race condition。

ETrain/Train/LLaVA/gradient_logger.py

class ModalGradientLogger: """ 支持：gradient_checkpointing / ZeRO-2 / ZeRO-3 / DDP 多 GPU：每个 rank 写 {task}_rank{N}_grad_stats.csv，分析时合并 """ def attach(self, model: nn.Module) -> None: """在每个 CoINMOELoraLinear 上设置三个属性，触发 hook 注册""" for name, module in model.named_modules(): if isinstance(module, CoINMOELoraLinear): module._log_gradients = True module._grad_logger = self module._grad_layer_name = name def step_end(self) -> None: self.step += 1 # 每个 optimizer step 后调用一次 def _flush(self, step, layer, g_tA, g_vA, g_tB, g_vB) -> None: """hook_A 触发后调用，追加一条记录""" if step % self.log_every_n_steps != 0: return self.records.append(_StepRecord(step, layer, g_tA, g_vA, g_tB, g_vB)) def save_csv(self, task_name: str) -> str: """训练结束时调用，写 {task}_rank{N}_grad_stats.csv""" rank = dist.get_rank() if dist.is_initialized() else 0 path = f"{self.output_dir}/{task_name}_rank{rank}_grad_stats.csv" # 写入 step, layer, G_text_A, G_vis_A, R_A, G_text_B, G_vis_B, R_B ...

CSV 结构（16 列，三指标全精确 + per-token 归一化）：

step, layer, G_text_A, G_vis_A, R_A, R_A_tok, G_text_B, G_vis_B, R_B, R_B_tok, G_text_dW,G_vis_dW,R_dW, R_dW_tok, n_text, n_vis 5, ...q_proj, 0.314,0.015, 20.7,19.4, 0.201,0.008,25.1,23.6, 0.285,0.011,25.9,24.3, 612,576 ...
step=0/1 时 G_text_A=0 是正常的：W_B 初始化为零，∂L/∂out_A=W_Bᵀ×∂L/∂out_B=0。分析时过滤 n_vis=0（纯文本 batch）和 g_vis_A < 1e-6。R_A_tok / R_dW_tok 消除 token 数量差异，是与 R_A / R_dW 对比的关键列。

train_grad.py — Callback 注入方式

不修改 train.py，通过 monkey-patch 在 LLaVATrainer 初始化时注入 callback：

ETrain/Train/LLaVA/train_grad.py

_grad_logger = ModalGradientLogger(log_every_n_steps=_log_every, output_dir=_grad_out_dir) class _GradLogCallback(TrainerCallback): def on_train_begin(self, args, state, control, model=None, **kw): torch.cuda.empty_cache() # 释放模型加载阶段的碎片内存 _grad_logger.attach(model) def on_step_end(self, args, state, control, **kw): _grad_logger.step_end() # 同步 step 计数 def on_train_end(self, args, state, control, **kw): _grad_logger.save_csv(_task_name) # monkey-patch：把 callback 塞进 LLaVATrainer.__init__ def _patched_init(self, *args, **kwargs): existing = list(kwargs.get("callbacks") or []) existing.append(_GradLogCallback()) kwargs["callbacks"] = existing _orig_LLaVATrainer_init(self, *args, **kwargs) _llava_trainer_mod.LLaVATrainer.__init__ = _patched_init

⑤ 工程问题及解决过程

问题根因解决方案
OOM v1：模块属性存张量 self._log_out_B = out_B 让 224 层的大张量同时驻留 GPU，14GB+ 改为在 hook 内部直接计算，不挂模块属性
G_text_A 始终为 0（step 0） W_B 初始化为零，第一步 ∂L/∂out_A = W_Bᵀ × ∂L/∂out_B = 0 正常行为，step ≥ 1 后 W_B 有值；分析时过滤 step=0
hook_B 读不到 A 的值 backward 顺序确定：out_B 在 out_A 之前触发；hook_B 触发时 hook_A 未写 hook_B 写 _pending[(step,layer)]，hook_A 来了再 pop 合并
DeepSpeed ZeRO-3 OOM（单卡） all-gather/free 循环在模型加载阶段造成显存碎片（reserved 4GB 但无 300MB 连续块） 改用单卡纯 Python 训练（无 ZeRO），17GB 可容纳 7B
代理指标的精度问题 ‖g_out_A × mask‖ 不含 x 幅度，需假设 ‖x_text‖≈‖x_visual‖ 升级为精确指标：einsum('tnr,td→nrd', g_t, x_t) + x_ref 闭包管理内存
多卡写 CSV race condition 多个 rank 同时写同一文件导致数据损坏 每 rank 写独立文件 {task}_rank{N}_grad_stats.csv，分析时 concat
hook_A 只取 batch[0]（bug） g_out_A[0, t_idx, ...] 丢弃其余 7 个样本，G 范数被低估约 1/√B 改为循环 B 个样本累加：for b in range(B): G_t += einsum(...[b],...)
