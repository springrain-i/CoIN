① 研究目标

研究问题：持续指令微调（T1→T8）中，MoELoRA 的文本梯度是否系统性主导参数更新，且这种主导是否随任务序号单调加剧？

核心指标：梯度主导比值，三个视角同时记录（全部精确）

$$R_A(k) = \frac{\|G^t_A\|_F}{\|G^v_A\|_F}, \quad R_B(k) = \frac{\|G^t_B\|_F}{\|G^v_B\|_F}, \quad R_{\Delta W}(k) = \frac{\|G^t_{\Delta W}\|_F}{\|G^v_{\Delta W}\|_F}$$ $$R_{X,\text{tok}}(k) = \frac{\|G^t_X\|_F / n_{\text{text}}}{\|G^v_X\|_F / n_{\text{vis}}}, \quad X \in \{A,\,B,\,\Delta W\}$$

其中（全部精确外积求和，全 batch）：

$G^t_A[n,r,d] = \sum_{b,\,t\in\text{text}} (\partial L/\partial\text{out}_A)[b,t,n,r]\;\cdot\;\text{lora\_x}[b,t,d]$  ·  形状 $(N,r,d_{\text{in}})$

$G^t_B[n,d,r] = \sum_{b,\,t\in\text{text}} (\partial L/\partial\text{out}_B)[b,t,n,d]\;\cdot\;\text{out\_A}[b,t,n,r]$  ·  形状 $(N,d_{\text{out}},r)$

$\|G^t_{\Delta W}\|_F^2 = \sum_b (K_{g,b} \odot K_{x,b})_{\text{sum}}$，其中 $K_{g,b}=g_b g_b^\top$，$K_{x,b}=x_b x_b^\top$（Gram Trick，见 Step 4b）

预期现象对应指标
文本梯度始终主导所有任务 R_A(k), R_B(k), R_dW(k) > 1
主导随任务序列加剧R_A(k), R_B(k), R_dW(k) 随 k 单调递增
消除 token 数效应后偏置仍成立R_A_tok(k), R_B_tok(k), R_dW_tok(k) > 1
这是视觉模态知识更易被遗忘的机制性原因与 text/visual acc 差距相关

Step 3 · 从 ∂L/∂h 到 ∂L/∂W_A 的完整推导（W_A 和 W_B）

W_A 的推导

Forward 展开为下标形式（t = 序列位置，i = 输出维度 r，j = 输入维度 d_in）：

h_A[t, i] = Σ_j W_A[i, j] · x[t, j] ← forward 的精确定义 对 W_A[i, j] 用链式法则求偏导： ∂L/∂W_A[i,j] = Σ_t (∂L/∂h_A[t,i]) · (∂h_A[t,i]/∂W_A[i,j]) ↑ ↑ G_out_A[t,i] 从 forward 读出 = x[t, j] = Σ_t G_out_A[t, i] · x[t, j] 写成矩阵乘法： ∂L/∂W_A = G_out_A^T @ x 形状验证：(r×T) @ (T×d_in) = r×d_in ✓

W_B 的推导

h_B[t, p] = Σ_i W_B[p, i] · h_A[t, i] · scaling ∂L/∂W_B[p, i] = Σ_t (∂L/∂h_B[t,p]) · h_A[t, i] · scaling 矩阵形式（MoE 版本，B shape=(N,d_out,r_per)）： ∂L/∂B[n,d,r] = Σ_{b,t} g_out_B[b,t,n,d] * out_A[b,t,n,r] 按模态分解（精确，已在代码实现）： G^t_B[n,d,r] = Σ_{b,t∈text} g_out_B[b,t,n,d] * out_A[b,t,n,r] G^v_B[n,d,r] = Σ_{b,t∈visual} g_out_B[b,t,n,d] * out_A[b,t,n,r] 内存：out_A.detach() 形状 (B,T,N,r) = (8,700,8,4) ≈ 0.36MB — 极小，可直接存闭包

ΔW = B@A 合并梯度（新增，精确）

ΔW(x) = B @ A @ x = lora_out / scaling （单 expert 情形；MoE 下为 router 加权和） ∂L/∂(ΔW)[d_out, d_in] = Σ_t (∂L/∂lora_out[t, d_out]) × lora_x[t, d_in] ← 直接从 lora_out 节点反传 = g_lora_out^T @ lora_x (d_out × d_in) 注：不显式构造此矩阵（64MB/层），用 gram matrix trick： ||G^t_dW||_F² = trace(Kg ⊙ Kx) Kg=(T_t,T_t), Kx=(T_t,T_t) 无大矩阵 物理含义：直接测量"LoRA 有效权重更新方向中 text 贡献占比"。 与 W_A 不同：W_A 测输入压缩子空间偏置；ΔW 测最终写入模型的等效权重偏置。

按模态分解（W_A 和 ΔW 精确，W_B 为 proxy）

对 W_A：把 x 拆成 x_text + x_visual ∂L/∂W_A = G_out_A^T @ x = G_out_A^T @ (x_text + x_visual) = G_out_A^T @ x_text + G_out_A^T @ x_visual = G^t_A + G^v_A 对 W_B：把 h_A 拆成 h_A_text + h_A_visual ∂L/∂W_B = G_out_B^T @ h_A = G_out_B^T @ h_A_text + G_out_B^T @ h_A_visual = G^t_B + G^v_B 关键性质：G^t + G^v = 完整梯度（精确等式，无近似，因为 x_text 和 x_visual 在 token 空间不重叠）

Step 4b · Gram Matrix Trick — ΔW 梯度范数的高效计算

ΔW 的文本梯度矩阵定义为： $$G^t_{\Delta W} \;=\; \sum_{b,\,t \in \text{text}} \mathbf{g}_{bt}^\top \mathbf{x}_{bt} \;=\; g_{\text{text}}^\top \, x_{\text{text}} \;\in \mathbb{R}^{d_{\text{out}} \times d_{\text{in}}}$$ 直接构造此矩阵代价为 $4096\times4096\times4\text{B}=64\text{MB/层}$，完全不可接受。 Gram Matrix Trick 用两个小矩阵绕开它。

推导

展开 Frobenius 范数定义：

$$\|G^t_{\Delta W}\|_F^2 = \sum_{d,\,i} G^t_{\Delta W}[d,i]^2 = \sum_{d,\,i} \Bigl(\sum_t g_t[d]\,x_t[i]\Bigr)^2$$

展开平方，引入双指标 $t_1, t_2$：

$$= \sum_{d,\,i}\; \sum_{t_1,t_2} g_{t_1}[d]\,x_{t_1}[i]\;g_{t_2}[d]\,x_{t_2}[i]$$

交换求和次序，把 $d,i$ 移到内层：

$$= \sum_{t_1,t_2} \underbrace{\Bigl(\sum_d g_{t_1}[d]\,g_{t_2}[d]\Bigr)}_{K_g[t_1,t_2]} \;\cdot\; \underbrace{\Bigl(\sum_i x_{t_1}[i]\,x_{t_2}[i]\Bigr)}_{K_x[t_1,t_2]} = \bigl(K_g \odot K_x\bigr)_{\text{sum}}$$

其中：

  • $K_g = g_{\text{text}}\,g_{\text{text}}^\top \in \mathbb{R}^{T_t\times T_t}$ — 梯度向量的 Gram 矩阵
  • $K_x = x_{\text{text}}\,x_{\text{text}}^\top \in \mathbb{R}^{T_t\times T_t}$ — 激活向量的 Gram 矩阵
  • $\odot$ 为逐元素乘法

直觉

$K_g[t_1,t_2]$ 衡量 token $t_1$ 与 $t_2$ 梯度方向的相似度；$K_x[t_1,t_2]$ 衡量它们输入激活的相似度。两者相乘：梯度方向一致且激活相似的 token 对，对 $\|G^t_{\Delta W}\|_F^2$ 贡献最大。

代价对比

方法内存FLOPs（T_t=600）
直接构造 $G$64MB/层$T_t \times d_{\text{out}} \times d_{\text{in}} \approx 10^{10}$
Gram Trick$2 \times T_t^2 \times 4\text{B} \approx 3\text{MB/层}$$2 \times T_t^2 \times d \approx 3\times10^9$（少 3×）
代码：g_t_sq += (g_t @ g_t.T * (x_t @ x_t.T)).sum().item() per-sample 累加后取平方根即为 $\|G^t_{\Delta W}\|_F$。

Step 5 · 为什么 R_A 实测是 20× 而不是 2-3×？

一个主要放大效应 + 一个反向校正效应，净结果 ≈ 20×：

注意：之前 HTML 版本中"效应①文本 token 数量多"的说法是错误的。ScienceQA 实测视觉 token 占 69%，效应②（token 数量差异）实际在压低 R，不是放大。效应①（loss 位置效应）需独立贡献约 30×，才能在 ×0.67 校正后得到实测的 20×。

Step 6 · MoELoRA 梯度共享：为什么 R_B(36×) > R_A(20×)

MoELoRA 有 N=8 个专家，每个专家有独立 W_A_i，但所有专家共享同一个 W_B。

梯度共享的核心含义： W_B 在 backward 中同时接收来自 8 条专家路径的梯度，这些路径在文本方向高度对齐（每个 W_A_i 都已经偏文本了），叠加导致 R_B > R_A。共享的 W_B 是文本偏置的放大器和集散地，也是持续学习中视觉表征退化的关键机制节点。

④ 代码实现

核心：coinmoelora.py — 三个 backward hook

触发顺序由计算图决定：hook_lora_out（ΔW，最先）→ hook_B（W_B proxy）→ hook_A（W_A，最后，负责 flush）。x_ref 在 hook_A 释放；hook_lora_out 读时仍有效。

x_ref[0] = None if logger_ref is None or step % log_every != 0: return with torch.no_grad(): G_t = torch.zeros(A_shape, dtype=A_dtype, device=A_device) G_v = torch.zeros(A_shape, dtype=A_dtype, device=A_device) for b in range(raw_mask.shape[0]): t_idx = (raw_mask[b] == 2); ModalGradientLogger — 记录器主类

负责 attach 到模型、协调 hook 结果、写 CSV。每个 rank 写独立文件，不会 race condition。

class ModalGradientLogger: """ 支持：gradient_checkpointing / ZeRO-2 / ZeRO-3 / DDP 多 GPU：每个 rank 写 {task}_rank{N}_grad_stats.csv，分析时合并 """ def attach(self, model: nn.Module) -> None: """在每个 CoINMOELoraLinear 上设置三个属性，触发 hook 注册""" for name, module in model.named_modules(): if isinstance(module, CoINMOELoraLinear): module._log_gradients = True module._grad_logger = self module._grad_layer_name = name def step_end(self) -> None: self.step += 1 # 每个 optimizer step 后调用一次 def _flush(self, step, layer, g_tA, g_vA, g_tB, g_vB) -> None: """hook_A 触发后调用，追加一条记录""" if step % self.log_every_n_steps != 0: return self.records.append(_StepRecord(step, layer, g_tA, g_vA, g_tB, g_vB)) def save_csv(self, task_name: str) -> str: """训练结束时调用，写 {task}_rank{N}_grad_stats.csv""" rank = dist.get_rank() if dist.is_initialized() else 0 path = f"{self.output_dir}/{task_name}_rank{rank}_grad_stats.csv" # 写入 step, layer, G_text_A, G_vis_A, R_A, G_text_B, G_vis_B, R_B ...
