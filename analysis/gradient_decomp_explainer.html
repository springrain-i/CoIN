模态梯度分解

为什么 dL/dW_A 可以无损地拆分为文本贡献 Gt 和视觉贡献 Gv

⓪ 前置知识：反向传播是怎么让模型变好的？

核心目标

训练的本质：调整模型的参数（权重矩阵），让模型的预测越来越接近正确答案。

Loss（损失） = 一个数字，衡量当前预测有多错。Loss 越小 = 预测越准。

目标：找到一组参数 W，使得 Loss(W) 最小

用最简单的例子理解：一个参数 w

假设模型只有一个参数 w，预测值 = w·x，目标是让预测值接近 y_true：

Loss = (w·x - y_true)² ← 预测误差的平方

多个参数时：每个参数都有自己的梯度

实际模型有很多参数（比如权重矩阵 W）。每个参数都需要计算「它对 Loss 的贡献是多少」：

∂Loss/∂W[i,j] = "W 的第 i 行第 j 列元素增大一点点时，Loss 会变多少"

所有参数的梯度合在一起，就是梯度矩阵 ∂Loss/∂W，形状和 W 完全一样。

链式法则：梯度如何穿过多层网络？

模型有很多层，Loss 是最终输出经过很多步变换得到的：

反向传播的本质：从 Loss 出发，用链式法则逐层往前计算每个参数的梯度，每层只需要「上游传来的梯度 × 本层的局部导数」。

在我们的 LoRA 场景里：
 • G_out_B = ∂L/∂h_B 就是「从 Loss 传到 W_B 输出的梯度」（上游梯度）
 • G_out_A = ∂L/∂h_A 就是「再经过 W_B 传到 W_A 输出的梯度」（更深层的上游梯度）
 • 它们都是 hook 在 backward 时自动能拿到的量。

① 先看输入 x 长什么样

一个 multimodal batch 里，序列中混有两种 token：

把整个序列的向量矩阵记作 x（形状 T × d_in），其中 T 是序列长度，d_in 是隐层维度。

现在把 x 按 token_mask 拆成两个矩阵：

x_text = x 中 mask==2 的行，其余位置填 0 # 形状仍是 T × d_in x_visual = x 中 mask==1 的行，其余位置填 0 # 形状仍是 T × d_in ✓ x = x_text + x_visual （两个矩阵在空间上不重叠，加起来还原原序列）

② LoRA Forward：W_A 做了什么？

Forward 阶段：W_A（形状 r × d_in）把输入 x 压缩到低秩空间，输出 h = x @ W_A^T（形状 T × r）。

Backward 阶段：从 Loss 反传回来的梯度叫 grad_output，形状 T × r，表示「h 的每个位置对 Loss 的贡献方向」。

③ 完整计算流程：Forward → Loss → Backward

把整个 LoRA 的 forward + backward 画在一张图里，标出每个中间量的形状：

两个关键观察：

  • G_out_B = ∂L/∂h_B：从 Loss 直接反传到 h_B 的梯度，在回答 token 位置幅度最大（因为 loss 只在那里产生）
  • G_out_A = ∂L/∂h_A：再经过 W_B^T 传回 h_A 的梯度，继续向前

④ 从 dL/dh 到 dL/dW：逐步推导（W_A 和 W_B）

第一步：理解 dL/dW_A 怎么算

Forward 展开为下标形式（t = 序列位置，i = 输出维度 r，j = 输入维度 d_in）：

h_A[t, i] = Σ_j W_A[i, j] · x[t, j] ← forward 的精确定义

对 W_A[i, j] 用链式法则求偏导：

∂L/∂W_A[i,j] = Σ_t (∂L/∂h_A[t,i]) · (∂h_A[t,i]/∂W_A[i,j]) ↑ ↑ G_out_A[t,i] 从 forward 直接读出 = x[t, j] = Σ_t G_out_A[t, i] · x[t, j]

把这个「对所有 T 个位置求和」的操作写成矩阵乘法：

∂L/∂W_A = G_out_A^T @ x 形状验证：(T×r)^T @ (T×d_in) = (r×T) @ (T×d_in) = r × d_in ✓ 与 W_A 形状一致

第二步：W_B 的推导（完全对称）

Forward 展开（t = 位置，p = d_out，i = r 维）：

h_B[t, p] = Σ_i W_B[p, i] · h_A[t, i] · scaling ∂L/∂W_B[p, i] = Σ_t (∂L/∂h_B[t,p]) · (∂h_B[t,p]/∂W_B[p,i]) ↑ ↑ G_out_B[t,p] = h_A[t, i] · scaling = Σ_t G_out_B[t, p] · h_A[t, i] · scaling 矩阵形式： ∂L/∂W_B = G_out_B^T @ h_A · scaling 形状验证：(T×d_out)^T @ (T×r) = (d_out×T) @ (T×r) = d_out × r ✓ 与 W_B 形状一致

第三步：按模态分解（W_A 和 W_B 完全对称）

对 W_A：把 x 拆成 x_text + x_visual：

∂L/∂W_A = G_out_A^T @ x = G_out_A^T @ (x_text + x_visual) ← x = x_text + x_visual = G_out_A^T @ x_text + G_out_A^T @ x_visual = G^t_A + G^v_A

对 W_B：把 h_A 拆成 h_A_text + h_A_visual（h_A = W_A @ x，同样可按 token 类型拆）：

h_A_text = h_A × (token_mask == 2, 其余位置置0) # T × r h_A_visual = h_A × (token_mask == 1, 其余位置置0) # T × r ∂L/∂W_B = G_out_B^T @ h_A = G_out_B^T @ (h_A_text + h_A_visual) = G_out_B^T @ h_A_text + G_out_B^T @ h_A_visual = G^t_B + G^v_B
三个关键点：
① 分解是精确的（G^t + G^v = 完整梯度），不是近似。
② W_A 用 x_text / x_visual 拆分，W_B 用 h_A_text / h_A_visual 拆分，后者是前者经过 W_A 变换后的结果。
③ G_out_A 和 G_out_B 都在 backward hook 里被捕获，不需要额外的 forward pass。

⑤ 直观理解：为什么 ‖G^t‖_F > ‖G^v‖_F？

图中这个例子里，文本 token 有 4 个，视觉 token 有 2 个（少）。
矩阵乘法里，参与累加的行越多，结果的 Frobenius 范数通常越大。
更重要的是，文本 token 的特征向量本身幅度更大（文本梯度信号更强）——这才是「过文本化」的根源。

⑥ R(k) 是什么，为什么要看它随任务的变化？

R(k) = ‖G^t_k‖_F / ‖G^v_k‖_F 其中 k = 任务序号（1=ScienceQA, 2=TextVQA, ..., 8=OCRVQA）
R(k) 的值 含义
R(k) = 1 文本和视觉对 W_A 的更新贡献完全均衡
R(k) > 1 文本主导更新，视觉知识容易被覆盖
R(k) 随 k 单调递增 随着顺序训练，文本主导越来越严重 → 视觉遗忘不断累积加剧

我们的实验目标就是：跑完 MoELoRA T1→T8，用上面的分解方法，实测画出这条曲线，为论文提供直接的机制性证据。

⑦ 实现上的 hook 机制

不需要修改 backward 逻辑，PyTorch 的 register_hook 可以在梯度流过时"旁听"：

# forward 时保存分模态输入 lora_x_text = lora_x * (token_mask == 2).float().unsqueeze(-1) # T×d_in，视觉位置=0 lora_x_visual = lora_x * (token_mask == 1).float().unsqueeze(-1) # T×d_in，文本位置=0 # 在 lora_A 的输出 h 上注册 hook def grad_hook(grad_output): # grad_output shape: T × r G_t = grad_output.T @ lora_x_text # r × d_in G_v = grad_output.T @ lora_x_visual # r × d_in logger.log(‖G_t‖_F, ‖G_v‖_F, layer_name) h = lora_x @ W_A.T h.register_hook(grad_hook)
1
Forward：计算 x_text, x_visual，保存在闭包里。
2
Backward：hook 被触发，拿到 grad_output，计算 G^t 和 G^v 的范数。
3
Logger 累积每步、每层的 ‖G^t‖ 和 ‖G^v‖，每 N 步写一次 CSV。
4
任务结束时，计算该任务的 R(k) = mean(‖G^t‖) / mean(‖G^v‖)，输出汇总。
关键性质：这个 hook 不改变任何梯度值，也不影响权重更新。它只是「旁观」并记录。训练结果与未加 hook 完全一致。

⑧ MoELoRA 的特殊结构

W_A 和 W_B 的推导见第 ④ 节。MoELoRA 有一个额外的结构需要注意：

MoELoRA：N 个专家，各持独立 W_A_i（i=0..N-1），共享 W_B output += W_B · ( Σ_i router_i · W_A_i · x ) · scaling ↑ 软路由加权求和（softmax 权重）

因此梯度分解需要 per-expert 进行：

对每个专家 i： h_A_i = W_A_i · x # 该专家的低秩激活 G^t_{A_i} = G_out_{A_i}^T @ x_text # 文本贡献 G^v_{A_i} = G_out_{A_i}^T @ x_visual # 视觉贡献 其中 G_out_{A_i} = router_i · W_B^T · G_out_B （router 权重缩放后的反传梯度） 对共享 W_B： h_A_all_text = Σ_i router_i · h_A_i_text # 所有专家文本激活加权和 h_A_all_visual = Σ_i router_i · h_A_i_visual G^t_B = G_out_B^T @ h_A_all_text G^v_B = G_out_B^T @ h_A_all_visual
参数数量分解方式
W_A_i（每个专家）N=8 个用 x_text / x_visual 分解，各自独立
W_B（共享）1 个用所有专家的 h_A 加权和拆分
实验中汇报 R(k) 时，W_A 取 8 个专家的平均 R，W_B 单独报告。如果两者趋势一致（都单调递增），论证更完整。

梯度如何从 loss 传回视觉 token？

G^t >> G^v 的双重原因

原因作用位置效果
① 文本 token 数量多于视觉 token x_text 的行数更多 G^t_A / G^t_B 累加项更多
② Loss 只在回答 token 产生直接梯度 grad_output 在文本位置幅度更大 G^t 的每一项幅度更大
视觉 token 只收到间接梯度（via attention） grad_output 在视觉位置幅度较小 G^v 的每一项幅度更小
两个效应叠加：文本 token 不仅「数量上」主导梯度累加，还在「幅度上」每个都比视觉 token 贡献更强的梯度信号。
随着顺序学习的任务越来越文本密集（TextVQA → OCRVQA），这个不平衡持续放大，直到第 8 个任务时 R(k) 达到最高——这正是我们实验要实测验证的。

⑩ 完整实现：W_A 和 W_B 的联合 hook

更新后的 hook 同时捕获 W_A 和 W_B 的分模态梯度：

# ── forward 中 ────────────────────────────────────────────── # 1. 按 token_mask 拆分输入 lora_x_text = lora_x * (token_mask == 2).unsqueeze(-1) # T×d_in lora_x_visual = lora_x * (token_mask == 1).unsqueeze(-1) # T×d_in # 2. W_A forward，注册 hook 捕获 grad_output_A（即 dL/dh_A） h_A = lora_x @ W_A.T # T × r def hook_A(grad_output_A): # shape: T × r G_t_A = grad_output_A.T @ lora_x_text # r × d_in G_v_A = grad_output_A.T @ lora_x_visual # r × d_in logger.log_A(‖G_t_A‖_F, ‖G_v_A‖_F) h_A.register_hook(hook_A) # 3. W_B forward，注册 hook 捕获 grad_output_B（即 dL/dh_B） h_A_text = h_A.detach() * (token_mask == 2).unsqueeze(-1) # T × r h_A_visual = h_A.detach() * (token_mask == 1).unsqueeze(-1) # T × r h_B = h_A @ W_B.T * scaling # T × d_out def hook_B(grad_output_B): # shape: T × d_out G_t_B = grad_output_B.T @ h_A_text # d_out × r G_v_B = grad_output_B.T @ h_A_visual # d_out × r logger.log_B(‖G_t_B‖_F, ‖G_v_B‖_F) h_B.register_hook(hook_B) # ── 训练结束时 ─────────────────────────────────────────────── # R_A(k) = mean(‖G^t_A‖) / mean(‖G^v_A‖) ← W_A 的文本主导比 # R_B(k) = mean(‖G^t_B‖) / mean(‖G^v_B‖) ← W_B 的文本主导比
最终记录的指标：每个任务 k、每个 attention 层（q/k/v/o proj）分别输出：
  • R_A(k, layer) — W_A 层的梯度主导比
  • R_B(k, layer) — W_B 层的梯度主导比
  • R_mean(k) — 所有层平均（论文中的主要图表）

期望结果：所有指标均满足 R > 1，且随 k 单调递增。
